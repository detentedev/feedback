# Détente feedback

This is where to report bugs, ask questions and request features for [Détente](https://detente.dev) during the
open beta. The application source is published at launch; until then, issues live here.

**Before you open an issue,** please include:

- which console you use (Android or the Linux terminal) and its version, from the about screen or `detente-tui --version`
- which harness your agent runs in (Claude Code, Codex, or another MCP harness)
- what you did, what you expected, and what happened instead

**Android test access:** open an issue with the "Android test access" template and the Google account you want
added.

**Security problems:** please do not report them here. A private security contact is being set up and will be
listed on detente.dev.
